# Apartamento San Francisco 3D

Passeio em primeira pessoa pelo escaneamento do apartamento, feito para abrir direto no celular (também funciona no computador).

- **Celular:** polegar esquerdo no círculo para andar, arraste o dedo direito para olhar. ⤒ pula, » corre, ☰ pausa.
- **Computador:** clique na tela, W A S D para andar, mouse para olhar, ESC para pausar.

Para testar no seu computador antes de publicar, dê dois cliques em `ABRIR_JOGO_WINDOWS.bat`.
